# yashverma-cloud.github.io

This site moved to <https://yashverma.cloud/>.

GitHub Pages stays on here, with `yashverma.cloud` as the custom domain, so that GitHub answers every old `yashverma-cloud.github.io` address with a permanent redirect to the same path on the new domain. Deleting this repository or turning Pages off breaks those links.

The site source is at <https://github.com/yashverma-cloud/yashverma.cloud>.
